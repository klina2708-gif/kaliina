# Генератор ТЗ

Одностраничный генератор тренировочных дизайн-брифов по авторскому макету.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

## Как расширять базу

Все варианты находятся в `src/data/randomizerData.js`. Чтобы добавить свой вариант, скопируйте ближайший объект и измените его текст и смысловые теги.

Исходные изображения находятся в `public/assets`. Переменная шрифта и комментарий для подключения оригинальной гарнитуры — в начале `src/styles.css`.

## Сборка и публикация

Cloudflare Pages собирает сайт из ветки `main` командой `npm run build`. Папка результата — `dist`.
